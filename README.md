# LG webOS Remote
For LG 32LM636BPTB. Requires Node.js 18+ on a computer on the same trusted Wi-Fi as the phone and TV. Not an APK. Run `npm install` then `npm start` in this folder. On Windows run `ipconfig` and find the computer's Wi-Fi IPv4 address. On Android Chrome open http://COMPUTER_IP:3000. Allow Node through the private-network firewall if prompted. Find the TV IPv4 address in its network settings, enter it in the remote, tap Connect TV and accept the pairing prompt on the TV. Chrome menu > Add to Home screen is optional. Keep the server running. Do not expose port 3000 to the internet or untrusted networks: this prototype has no user authentication and uses the TV's self-signed TLS certificate. Pairing keys are stored locally in keys.json. Power on uses Wake-on-LAN and requires TV support, compatible standby settings and MAC address; it may not work on this model or Wi-Fi. App shortcuts and settings depend on firmware. The implementation has not been tested on physical hardware. No IR support. If pairing fails, verify TV network settings and firmware support for third-party remote control.
